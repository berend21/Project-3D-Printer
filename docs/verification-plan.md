
# System Verification Plan

**Document ID:** SYS-VVP-001
**Revision:** 0.1
**System:** Custom CoreXY 3D Printer

## 1. Purpose

Define the approach for verifying the
mechanical, electrical and software behavior
of the assembled printer.

## 2. Verification methods

Inspection:
Visual or dimensional examination of
components and assemblies.

Analysis:
Evaluation using engineering calculations
or validated simulation methods.

Demonstration:
Observation of system functionality.

Test:
Measurement of actual system behavior.

## 3. Verification stages

### Stage 1: Mechanical verification
- Frame dimensional inspection.
- Frame alignment.
- Rail alignment.
- Gantry geometry.
- Belt and pulley inspection.

### Stage 2: Electrical verification
- Wiring inspection.
- Protective earth verification.
- Connector identification.
- Sensor functionality.
- Heater functionality.
- Protection system verification.

### Stage 3: Firmware verification
- Configuration review.
- Homing functionality.
- Motion direction.
- Endstop functionality.
- Probe functionality.
- Thermal monitoring.

### Stage 4: Performance verification
- Motion accuracy.
- Motion repeatability.
- Temperature stability.
- Extrusion performance.
- Reference print measurements.

## 4. Test record requirements

Each test shall record:

- Test identification.
- Related requirement.
- Machine configuration.
- Instrument identification.
- Test procedure.
- Acceptance criteria.
- Measured results.
- Deviations.
- Conclusion.
- Supporting evidence.

## 5. Test result classification

PASS:
All acceptance criteria satisfied.

FAIL:
One or more acceptance criteria not satisfied.

BLOCKED:
Test cannot be completed.

NOT TESTED:
No verification activity performed.

## 6. Final verification status

The machine is currently assembled and
operational.

Formal verification of the requirements
will be established through the documented
test campaign.
